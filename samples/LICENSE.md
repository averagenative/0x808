# Sample License

Samples in this directory come from a mix of public-domain / royalty-free
recordings (the original drum-machine pack) and externally-sourced kits
that require attribution under their respective licenses (Pearl,
Cassette).

## Royalty-free, no attribution required

| Directory     | Source                         |
|---------------|--------------------------------|
| `808/`        | Roland TR-808 Rhythm Composer  |
| `909/`        | Roland TR-909 Rhythm Composer  |
| `505/`        | Roland TR-505 Rhythm Composer  |
| `kicks/`      | Assorted kick drum samples     |
| `snares/`     | Assorted snare drum samples    |
| `hihats/`     | Assorted hi-hat samples        |
| `percussion/` | Assorted percussion one-shots  |
| `mrk2/`       | Assorted drum kit samples      |
