# v1.1.0 Changelog

## New Effects (8 added, 15 total)

- [x] **Bitcrusher** — bit depth reduction + sample rate decimation for lo-fi
- [x] **Compressor** — envelope follower with threshold/ratio/attack/release/makeup
- [x] **Phaser** — 6-stage allpass chain with LFO modulation and feedback
- [x] **Flanger** — short modulated delay with negative feedback support
- [x] **Tremolo** — volume LFO with sine/square/triangle waveforms
- [x] **Ring Modulator** — frequency multiplication by sine oscillator
- [x] **Tape Saturation** — tanh soft clipping + one-pole warmth filter
- [x] **Shimmer** — reverb tail with octave-up pitch shift + phaser modulation

- [x] **Synthwave** (105 BPM) — punchy kick, gated snare, open hi-hats on off-beats, tom quarters
- [x] **Punk** (180 BPM) — fast alternating kick, snare 2&4, crash accents
- [x] **Surf** (150 BPM) — tom-driven pattern, driving rhythm, ride cymbal
- [x] **Metal** (160 BPM) — double kick pattern, heavy snare, 16th-note hi-hats
- [x] **Indie** (115 BPM) — syncopated kick, ghost notes, cross-stick
